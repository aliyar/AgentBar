AgentBar {{VERSION}}
What the coding agents on this Mac are doing, and how much of their quota is left —
in the menu bar, in the Dock, and as a macOS widget.

────────────────────────────────────────────────────────────
INSTALL

1. Unzip this file (double-click it).
2. Drag AgentBar.app into your Applications folder.
3. Open it. This build is signed with a Developer ID certificate and
   notarized by Apple, so macOS opens it without a warning.

────────────────────────────────────────────────────────────
FIRST RUN

AgentBar lives in the menu bar (look for the gauge) — there is no Dock icon
unless you turn it on in Settings. Click the gauge for the meters and the
running conversations; right-click for Settings and Quit.

Everything is read from the agents' own files on this Mac (~/.claude, ~/.codex).
No account is contacted, no credential is ever seen, nothing leaves the machine.

UPDATES

AgentBar checks for new versions once a day and can update itself.
You can also check manually in Settings.

REQUIREMENTS

macOS {{MIN_MACOS}} or later.
